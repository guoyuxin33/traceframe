# Security policy

## Supported versions

Traceframe has no tagged public release yet. Security fixes are applied to the latest development state on `main`; older commits and locally built previews are not maintained as separate supported versions.

The macOS bundle is not yet signed or notarized. Do not treat a locally built preview as a production distribution.

## Reporting a vulnerability

Do not open a public issue containing exploit details, credentials, private repository content, or other sensitive data.

Use GitHub private vulnerability reporting. Do not include sensitive details in a public issue:

https://github.com/guoyuxin33/traceframe/security/advisories/new

No response or remediation deadline is guaranteed during the developer-preview stage.

Include the affected commit, platform, reproduction conditions, impact, and any suggested mitigation in the private report.
